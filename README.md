# Guia de Decisão e Pesquisa de Carro: Rio de Janeiro (RJ)
### Uso Diário + Renda Extra Uber Black (2027+) + Opção Híbrido (18 Modelos Analisados)

Este repositório reúne o dossiê completo de pesquisa, análise técnica, cálculo financeiro, **fontes oficiais de preço** e simulador interativo para a compra do seu próximo carro no **Rio de Janeiro**.

---

## 🧭 Resumo dos Requisitos do Seu Perfil
- **Localização:** Rio de Janeiro / Região Metropolitana (asfalto irregular, calor extremo de verão, engarrafamentos urbanos, alíquotas tributárias específicas);
- **Finalidade:** Carro próprio de **uso diário urbano**, com a estratégia de servir como **"carta na manga" para Uber Black** (renda extra eventual sem risco de bloqueio de modelo);
- **Porte:** Compacto a médio (fácil de manobrar e estacionar em vagas de rua ou garagens antigas no RJ);
- **Câmbio:** Estritamente **Automático / CVT / e-CVT** confiável e suave;
- **Combustível:** **100% Flex (Gasolina/Etanol) ou Híbrido** — **Zero GNV** (preserva 100% do porta-malas para bagagens de aeroporto e mantém a integridade mecânica);
- **Custos Racionais:** Atenção a custos de seguro no RJ, IPVA (4,0% Flex vs. **1,5% Híbrido**), manutenção preventiva, disponibilidade de peças de reposição e liquidez de revenda.

### 🚀 Como Hospedar no seu GitHub Pages (Passo a Passo em 1 Minuto)

Hospedar no GitHub Pages é 100% gratuito, profissional e gera um link limpo (`https://seunome.github.io/carro`) para você enviar no WhatsApp:

1. No terminal do PowerShell, inicialize o git e faça o primeiro commit:
   ```bash
   cd .
   git init
   git add .
   git commit -m "Catálogo de Carros RJ 2027"
   ```
2. Crie um repositório vazio no seu GitHub (ex: `carro`) e envie os arquivos:
   ```bash
   git remote add origin https://github.com/SEU_USUARIO/carro.git
   git branch -M main
   git push -u origin main
   ```
3. No GitHub, vá em **Settings** > **Pages** > em *Branch*, selecione **main** e pasta **/(root)** > clique em **Save**.
   * Pronto! Em 30 segundos seu link estará no ar com HTTPS seguro e as fotos funcionando em qualquer celular!
